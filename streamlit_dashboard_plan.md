## Streamlit Dashboard Plan

### Purpose
The Streamlit application will present the main findings from the
Jupyter Notebook in an interactive format suitable for technical
and non-technical users.

### Planned Pages

1. Home / Overview
   - Research question
   - Project motivation
   - Headline statistics
   - Key findings

2. SST & Seasonal Analysis
   - Seasonal filters
   - SST statistics
   - SST distribution
   - Observations by season
   - SST by season
   - Yearly SST trends

3. Observation Map
   - Interactive map of recorded humpback whale observations
   - Filters for season and year
   - Exploration of geographical patterns

4. SST Prediction
   - User inputs for year, month, latitude and longitude
   - Limited-depth Decision Tree model
   - Predicted SST
   - Explanation of model limitations

5. Methodology & Limitations
   - Data source and cleaning
   - Statistical methods
   - Machine-learning methodology
   - Limitations
   - Ethics and AI usage
